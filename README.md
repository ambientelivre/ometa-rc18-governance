# ometa-rc18-governance
BACEN RC 18 - Governança &amp; Dossiê de Auditoria para OpenMetadata

## Install in Linux

git clone

Access Your OpenMetadata UI in -> Settings -> Bots -> Governance-bot - Copy Token JKT 

export OPENMETADATA_JWT_TOKEN="Your token"

export OPENMETADATA_URL="http://seu-server:8585"

chmod 755 ./install_rc18_app.sh 

./install_rc18_app.sh
